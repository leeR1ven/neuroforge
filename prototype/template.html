工具模式

神经元

神经元本身不分类型，靠颜色区分就够了。跟外界打交道的那几个用接口标记，编译时会变成模型的输入 / 输出。
激活函数里有三种带状态的：记忆 Memory（把上一拍的值留到下一拍）、漏电积分 Leaky、脉冲 LIF。选了它们，右边的「偏置 bias」就变成保持系数 k：0 = 每拍清空（只剩当拍），1 = 完全不忘。模拟激活和编译出来的模型都按这条算；ONNX 导出不带状态（导出时会提示）。

按坐标放置

快捷铺设用上面的「步进单位」当间距：铺一列 = 数量 X 个沿 X 轴排开；铺一面 = 数量 X × 数量 Y 的一张平面；铺一方 = 三轴都铺成立体块。铺完原点顺移到这一片之后，接着铺下一片不会重叠。

用于验证规模性能，生成后观察帧耗时与内存占用。

显示

模型大起来之后，远看只画抽样点云和细线（看得清大致形状和权重分布），拉近才换成完整连线。要一直看全细节就把上面锁成「高」，代价是帧率。

相机 / 视角中心

右键拖拽 = 旋转，中键拖拽或方向键 = 上下左右平移（按住方向键会持续滑行、松手缓停，不是一格一格跳），滚轮 = 缩放。旋转是绕着「视角中心」转的：默认中心是世界原点，所以只转不挪就会一直盯着原点。选中神经元 / 连线后点「以选中为中心」就换成绕着它们转（视距、方向都不变），「聚焦选中」连视距一起调好。什么都没选时聚焦 = 框住整张图。

流式载入

打开时只读文件头，先把每块的包围盒画成线框；相机靠近哪一块，才把哪一块解压进内存。屏幕外的块不占实例缓冲。
已载入块0 / 0
分块方式—
神经元0 / 0
已读 / 全文件—
已驱逐0
权重块分段0 / 0
权重块在文件里是「一块一段」存的（每段带自己的包围盒），所以可以只读相机附近的那几段，远处的段一个字节都不碰。旧文件整段存的，就只能整段读。
超出上限时，离相机最远的块会被丢掉，腾出地方装新的——这样才能在上限之内一直往前飞。手上正在用的（选中神经元、悬停、连线起点所在的块）不会被丢。要说清楚：驱逐省的不是内存（实例缓冲是静态预分配的），省的是「上限之内能无限漫游」；它还会清空撤销记录——驱逐是资源事件，不是一次编辑。
