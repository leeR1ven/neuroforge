Place neurons. Wire them up.
Get a model that actually runs.

NeuroForge is a visual neural-network builder. Draw the network in 3D, press F7, and get PyTorch, ONNX, or a standalone binary that needs no Python at all. Everything runs on your machine — no account, no cloud, no upload.

A network built here was wired to a MuJoCo simulation of a Unitree Go2 quadruped. Driving nothing: the trunk settles at 0.18. Feeding five cells of each of the 12 muscles: it rises to 0.26 and holds. Run the same loop through the compiled binary: identical numbers.

Why not just write PyTorch?

It doesn't just draw it — it compiles it

PyTorch, ONNX, or C with the weights baked into the binary. The standalone build has zero dependencies and starts in milliseconds.

Spiking and recurrent networks included

Loops, feedback and self-connections all compile — unrolled over time. Memory, leaky-integrator and LIF spiking neurons keep their state for real.

It talks to real hardware

UDP, TCP, serial, WebSocket, or real key injection. Values flow in and out of the network live, at the tick rate.

You can see what it's doing

Weight histograms, activation flowing wave by wave, global health checks, pruning. A model viewer shows you the shape; this shows you the state.

Your first 10 minutes

  1. Install and open. The installer puts it in your user folder — no admin rights needed. Or just double-click the single-file HTML.
  2. Set up the assistant — it is the interface. In the bottom-right panel, click Settings. Cloud: paste one API key. Local: pick Ollama, and it costs nothing and never leaves your machine. Screenshot walkthrough: setting up the API.
  3. Then just say what you want. For example: place 20 neurons along X from (0,0,0), step 10, then chain them in a line. Placing, wiring, weights, simulating and compiling are all things it can do for you, and every change it makes is one Ctrl+Z away.
  4. Box-select a few neurons, then hit Simulate in the right panel and watch the signal travel wave by wave.
  5. Press F9 to flip to the structure view — the operator graph as it looked before it was flattened into neurons.
  6. Now build your own. A places neurons, W wires them, F7 compiles. Stuck anywhere? Ask the assistant.
